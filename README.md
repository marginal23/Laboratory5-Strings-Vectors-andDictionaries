# Лабораторная 05 – Строки, векторы и словари. Вариант 10

Одна программа `main.cpp`. Первая строка ввода выбирает часть: `A`, `B`, `C` или `D`.
Дальше программа читает только данные выбранной части. Пустой результат – `EMPTY`,
неверный ввод – `INVALID`.

## Сборка и запуск

```bash
g++ -std=c++17 -Wall -o main main.cpp
./main
```

## Части и примеры ввода

**A – нижний регистр.** Вторая строка – текст ASCII длиной до 200 символов (читается через `getline`).

```
A
  Cat a12  dog Cat  
```
Ответ: `  cat a12  dog cat  `

**B – развернуть.** Число `n` от 0 до 100, затем `n` целых `|x| ≤ 1000`.

```
B
7
-2 0 3 3 -1 4 0
```
Ответ: `0 4 -1 3 3 0 -2`

**C – накопление значения.** Число пар, пары «ключ значение» (повторный ключ заменяет значение),
затем ключ запроса и приращение от −1000 до 1000. Отсутствующий ключ сначала получает 0.

```
C
4
beta 2
alpha 5
beta 3
gamma -1
beta 4
```
Ответ: `alpha 5, beta 7, gamma -1`

**D – проверка адресной книги.** Число записей, затем для каждой записи `name` и `email` на отдельных строках.
Выводятся имена записей, у которых в адресе не ровно один `@`, нет символа до или после `@` или есть пробел.

```
D
4
Anna
anna@example.org
Boris
boris.example.org
Chris
@example.org
Dana
d@x@y
```
Ответ:
```
Boris
Chris
Dana
```
