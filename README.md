## Цель
Научиться обрабатывать текст с помощью `string`, хранить последовательности в `vector`
и находить данные по ключу в `map`, а затем объединить эти конструкции в обработке списка записей.

## Описание
Одна программа выполняет четыре части варианта. Первая строка ввода выбирает часть:
`A`, `B`, `C` или `D`, после неё программа читает только данные выбранной части.

- **A – нижний регистр.** Переводит латинские буквы строки в нижний регистр (`string`).
- **B – развернуть.** Выводит элементы последовательности в обратном порядке (`vector<int>`).
- **C – накопление значения.** Прибавляет приращение к значению ключа в словаре (`map<string, int>`).
- **D – проверка адресной книги.** Выводит имена владельцев записей с неверным адресом
  (`vector<map<string, string>>`, результат в `vector<string>`).

## Входные данные
- **A:** строка ASCII длиной до 200 символов, читается целиком через `getline`.
- **B:** число `n` от 0 до 100, затем `n` целых чисел, `|x| ≤ 1000`.
- **C:** число пар от 0 до 100, затем пары «ключ значение» по одной на строке
  (ключ – слово ASCII до 40 символов, значение от −1000 до 1000, повторный ключ заменяет значение),
  затем ключ запроса и приращение от −1000 до 1000.
- **D:** число записей от 0 до 100, затем для каждой записи `name` и `email` на отдельных строках.
  Каждое поле – ASCII длиной от 1 до 200 без пробела в начале и в конце.

## Выходные данные
- **A:** преобразованная строка, пробелы сохраняются.
- **B:** элементы через пробел в обратном порядке.
- **C:** итоговый словарь, по одной паре «ключ число» на строке в порядке ключей.
  Отсутствующий ключ сначала получает 0.
- **D:** имена записей, у которых в адресе не ровно один `@`, нет символа до или после `@` или есть пробел,
  по одному на строке в исходном порядке.
- Пустой результат – `EMPTY`, неверный ввод – `INVALID`.

## Пример
Ввод:
```
C
4
beta 2
alpha 5
beta 3
gamma -1
beta 4
```
Вывод:
```
alpha 5
beta 7
gamma -1
```

## Как запустить
Visual Studio: открыть `main.cpp` в консольном проекте и запустить без отладки (Ctrl+F5).

g++:
```bash
g++ -std=c++17 -Wall -o main main.cpp
./main
```
